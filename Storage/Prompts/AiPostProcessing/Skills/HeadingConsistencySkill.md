# Skill: Heading Consistency

The Markdown heading hierarchy must be consistent.

Rules:

1. There must be exactly one H1 document title.
2. Main sections must be H2.
3. Subsections must be H3.
4. Do not jump from H1 directly to H4.
5. Do not use different heading levels for sections of the same type.
6. If "I. ..." is H2, then "II. ...", "III. ...", and "IV. ..." must also be H2.
7. If a heading appears in the source, preserve it unless it is clearly a repeated page header.
8. Do not create headings from ordinary bold phrases inside paragraphs.
